# Reporting a security issue

Use GitHub’s private vulnerability reporting form to contact the Everock maintainers about a suspected security issue in the SDK, framework adapters, CLI, MCP server, or hosted collector. [Report a vulnerability privately](https://github.com/ELPROFUG0/everock-sdk/security/advisories/new).

Include the affected package and version, the behavior you observed, and its potential impact. For a hosted request, include the approximate UTC time and request identifier if available. Redact API keys, session cookies, and personal or customer data from logs and screenshots.

If a credential was exposed, revoke or rotate it with its issuer. Clearly identify the credential type in your report and keep the value private.
